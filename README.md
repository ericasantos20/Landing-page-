# ☕ ES Cafeteria — Landing Page

Landing page responsiva de uma **cafeteria fictícia**, desenvolvida com **HTML5 e CSS3** com o objetivo de praticar e aprimorar conhecimentos em desenvolvimento Front-End.

## 🌐 Visualize o projeto

[**🔗 Ver Projeto Online**](https://ericasantos20.github.io/Landing-page-cafeteria-ES/)

## 📖 Sobre o projeto

A **ES Cafeteria** é um projeto fictício criado para colocar em prática conhecimentos de desenvolvimento Front-End e explorar a criação de uma interface moderna e agradável para uma cafeteria.

A landing page apresenta diferentes seções, incluindo apresentação da cafeteria, informações sobre o estabelecimento, menu de produtos, avaliações de clientes e localização.

O projeto foi desenvolvido exclusivamente para **fins de estudo e portfólio**, permitindo praticar conceitos de estruturação, estilização e organização de uma página web.

## 🛠️ Tecnologias Utilizadas

- **HTML5** — Estruturação e marcação semântica
- **CSS3** — Estilização, layout e responsividade

## ✨ Funcionalidades

- 🏠 Seção inicial de apresentação
- ☕ Seção "Sobre Nós"
- 🍰 Menu com produtos da cafeteria
- 🛒 Botões para adicionar produtos ao carrinho
- ⭐ Seção de avaliações de clientes
- 📍 Seção de localização
- 📱 Layout responsivo
